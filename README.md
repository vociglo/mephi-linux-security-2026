# MEPHI Linux Security Homework 2026

Операционная система: РЕД ОС 7.3.

## Раздел 1. Пользователь
Создан user1 с UID 1234, основной группой students и максимальным сроком действия пароля 90 дней.

## Раздел 2. Мониторинг
Найдены файлы с битом set-UID и проверены процессы с эффективным UID 0 и реальным UID обычного пользователя.

## Раздел 3. Set-UID
Создана копия cat-suid с битом set-UID. Проверено чтение специально созданного защищённого тестового файла.

## Раздел 4. Linux capabilities
Для копии chown-cap установлена привилегия cap_chown=ep. Проверено изменение владельца тестового файла пользователем user1.

## Раздел 5. Sudo
Создано правило sudo для выполнения timedatectl set-time пользователем user1.

## Раздел 6. Артефакты
Приложены история команд, результаты stat, getcap, мониторинга файлов и процессов, подтверждение sudo и скриншот.

## Безопасность
Вместо полного /etc/shadow опубликована выдержка с удалённым хешем пароля. Системные файлы представлены в виде выдержек, относящихся к заданию.
